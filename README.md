# Tunmise Olaleye — Website Design & YouTube Promotion

Portfolio and lead-generation website for Tunmise Olaleye, offering premium website design and YouTube promotion services.

## What's in this repo

- `index.html` — the full site (single page)
- `styles.css` — all styling
- `script.js` — interactions (mobile nav, magnetic buttons, animated counters, scroll reveal, before/after slider, theme toggle, contact form)
- `assets/` — images used across the site

## Hosting

This site is static — no build step, no dependencies. It's hosted with GitHub Pages directly from this repository.

To update the live site: edit the files, commit, and push to the `main` branch. GitHub Pages redeploys automatically within a minute or two.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
